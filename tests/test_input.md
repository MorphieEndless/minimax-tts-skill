# 什么是熵？

**熵**（entropy）是系统的混乱程度，记作 $S$。公式 $S = k_B \ln W$ 中，
$k$ 是玻尔兹曼常数。（停顿）简单说，（笑）熵越大，系统越混乱。

- 熵增加，系统趋于无序
- 熵减少，需要外界做功
