# 转换规则全集（决策树版）

本文件是 SKILL.md 中规则的完整展开，供复杂稿逐条对照。

## 输入类型判定

先判断输入属于哪类，决定走哪条流水线：

| 输入特征 | 判定 | 说明 |
| --- | --- | --- |
| 含 `#`、`**`、`[text](url)`、列表符、表格 | Markdown 稿 | 走 Markdown 剥离 |
| 含 `$...$`、`$$...$$`、`\frac`、`\alpha` 等 | LaTeX/学术稿 | 走公式口语化 |
| 含 ``` ``` ``` 或缩进代码 | 技术稿 | 代码块默认剥离 |
| 含 `<html>`、`<div>` 或网页正文 | HTML 稿 | 剥标签留文本 |
| 含 （笑）（叹气）（停顿）等 | 口播稿/剧本 | 语气词映射 |
| 以上都没有 | 纯文本 | 只做停顿策略 + 校验 |

混合稿按 SKILL.md 的顺序逐层处理，先代码块 → 再 LaTeX → 再 HTML → 再 Markdown → 再特殊符号 → 再停顿 → 再语气词 → 校验。

## 一、代码块

```text
围栏代码块（``` 或 ~~~）：
  默认：整块删除，替换为"（代码略）"
  用户要求读代码：保留，但做代码口语化
    - 常见符号：_ → 下划线；-> → 指向；== → 等于；[] → 括号读法
    - 每行过长（>80 字符）建议分行，行尾加 <#0.2#>
行内代码 `...`：
  剥反引号，内容保留并进入后续符号处理
缩进代码（4 空格）：按围栏代码处理
```

## 二、LaTeX 口语化

### 处理顺序

1. 先找块级 `$$...$$`（多行优先），再找行内 `$...$`，最后 `\(...\)`。
2. 块级公式前后各加一个换行；公式口语化后若超过 20 个汉字，前后加 `<#0.3#>`。
3. 递归展开：最内层括号/命令先转。

### 括号与嵌套

- `(a+b)` → "a 加 b"（括号在口语中通常省略，除非是函数参数：`f(x)` → "f 括号 x" 或 "f 在 x 处的值"）。
- `\frac{分子}{分母}` 当分子分母为多项时，分母前插入短停顿：`(x 的平方加 1)<#0.2#>分之(x 减 1)`。
- 连乘 `a \times b \times c` → "a 乘 b 乘 c"。

### 兜底

- 含 `\begin{matrix}`、化学式、超过两层嵌套的复杂结构 → 剥离并报告"公式省略：<原公式>（建议人工确认是否朗读）"。
- 用户明确"公式不要读"→ 一律剥离，报告数量。

## 三、HTML 剥离

| 标签 | 处理 |
| --- | --- |
| `<br>`、`<br/>`、`</p>`、`</div>`、`</li>` | 换行 |
| `<h1>..<h6>` | 剥标签，按 Markdown 标题规则加停顿 |
| `<a href="...">文字</a>` | 只留文字 |
| `<img>` | 剥离，报告"图片：alt 或 src 说明" |
| `<code>`、`<pre>` | 按代码块规则 |
| 其余标签 | 剥标签留内部文本 |
| 实体 `&nbsp; &amp; &lt; &gt; &quot;` | 转空格、和、小于号、大于号、引号 |

## 四、Markdown 剥离（补充细节）

- **标题**：`#` 后剥标记；一级标题前 `<#0.5#>`；标题内部若含 `**` 一并剥。
- **链接**：`[文字](url "title")` → 只留文字。
- **列表嵌套**：二级列表项目前加"其中"，各项间 `<#0.2#>`。
- **任务列表** `- [x]` → "已完成：…"；`- [ ]` → "待办：…"。
- **表格**：表头一行读出列名；每行数据读出对应值；行间 `<#0.3#>`；单元格内容用逗号连接。
- **数学公式在 Markdown 里**：`$...$` 先行处理（顺序在 Markdown 之前，防止 `*` 冲突）。
- **脚注** `[^1]` 与 `[1]:` 定义 → 剥离，脚注正文若重要可并入文末"补充说明"。

## 五、特殊符号

- `&` → 中文语境"和"，英文语境"and"；URL 中的 `&` 随 URL 一起剥离。
- `%` → 统一"百分之"；`‰` → "千分之"。
- `±` → "正负"；`×` → "乘"；`÷` → "除以"；`≈` → "约等于"；`≠` → "不等于"；`≤ ≥` → "小于等于 大于等于"。
- `→ ← ↑ ↓` → "指向/推出、退回、向上、向下"。
- `℃ ℉` → "摄氏度、华氏度"。
- `°`（角度）→ "度"。
- `#` 后面跟数字（如 `#3`）→ "三号"或"井号三"（按语境）。
- emoji 映射（仅 2.8 模型，否则剥离）：
  - 开心类（😄😊😁🥳）→ `(chuckle)` 或 `(laughs)`
  - 难过类（😢😭😞）→ `(sighs)`
  - 惊讶类（😲😮）→ `(gasps)`
  - 疲惫/叹气类（😮💨🥱）→ `(exhale)` 或 `(sighs)`
  - 其他 → 剥离
- 重复标点：`！！！` → 单叹号，句子读重；`？？` → 单问号；`。。。。。` → 单句号。
- 连续省略号 `……` / `...` → `<#0.4#>`（停顿策略处理）。
- 破折号 `——`：表停顿 → `<#0.3#>`；表转折 → 保留为"但是/不过"等连接词（按语境）。

## 六、停顿策略（完整决策）

判定顺序：
1. 该位置是否已有标点（，。！？；）→ 不插，海螺自然停顿。
2. 该位置是否在名字/复合词中间 → 不插。
3. 该位置是否是段落边界 → 用换行，不插标记。
4. 以上都不是，才考虑按密度插。

密度档位：

| 档位 | 句间 | 强调前 | 列举项 | 省略号/破折号 |
| --- | --- | --- | --- | --- |
| none | — | — | — | 保留原符号 |
| light（默认） | — | `<#0.5#>` | `<#0.2#>` | `<#0.4#>` / `<#0.3#>` |
| medium | `<#0.3#>` | `<#0.5#>` | `<#0.2#>` | 同上 |
| strong | `<#0.3#>` | `<#0.5#>` 前后 | 逗号→`<#0.2#>` | 同上 |

强调点判定：话题转换词（但是、然而、重点、关键、结论）、首次出现的重要概念、反问句前。一稿强调停顿 ≤5 处。

## 七、语气词映射（完整决策）

1. 先扫官方标签：`(laughs)` 等 19 个原样保留（仅 2.8 模型）。
2. 再扫中文动作标注：全角/半角括号、方括号、尖括号里的动作词按 SKILL.md 映射表转换。
3. 频率控制：一段 ≤2 个；同类不重复（两处 (sighs) 合并一处）。
4. 位置：情绪标签放句首或句尾；`(breath)` 换气放长句中间靠前处最自然（如列举前）。
5. 非 2.8 模型：全部删除，报告"语气词 X 个已清除（模型不支持）"。
