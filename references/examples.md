# 转换示例集

## 示例 1：Markdown 口播稿（默认流程）

**输入：**

```markdown
# 今天聊三个提升效率的习惯

第一，**列清单**。把今天要做的三件事写下来，[参考模板](https://example.com/template)可以帮你起步。

第二，*屏蔽通知*。工作的时候，把手机调成勿扰模式。

> 记住：清单不在多，在精。

- 早上列三件事
- 中午检查一次
- 晚上复盘三分钟
```

**输出（speech-2.8-hd）：**

```
<#0.5#>今天聊三个提升效率的习惯
第一，列清单。把今天要做的三件事写下来，参考模板可以帮你起步。
第二，屏蔽通知。工作的时候，把手机调成勿扰模式。
记住：清单不在多，在精。
早上列三件事<#0.2#>中午检查一次<#0.2#>晚上复盘三分钟。
```

**报告：** 剥离加粗 1、斜体 1、链接 1、引用 1、列表 3；插入停顿 4；语气词 0。原 121 字 → 新 98 字。

## 示例 2：学术稿（LaTeX 公式口语化）

**输入：**

```markdown
玻尔兹曼熵公式为 $S = k_B \ln W$，其中 $W$ 是微观状态数。
自由能定义为 $F = U - TS$。
当 $\Delta G \leq 0$ 时反应自发进行。
```

**输出：**

```
玻尔兹曼熵公式为 S 等于 k 下标 B ln W，其中 W 是微观状态数。
自由能定义为 F 等于 U 减 T S。
当德尔塔 G 小于等于 0 时反应自发进行。
```

**报告：** 公式口语化 3 处（`\ln` 保留为 ln，`\Delta` → 德尔塔，`\leq` → 小于等于）；未插入停顿（句子本身有逗号）。

## 示例 3：播客/口播（动作标注密集）

**输入：**

```
（深呼吸）各位好，欢迎回到节目。（笑）今天这期我们聊一个特别反常识的话题：为什么越忙的人越有时间？
（停顿）答案可能让你意外——（倒吸气）它跟"效率"其实没什么关系。
```

**输出：**

```
(breath)各位好，欢迎回到节目。(chuckle)今天这期我们聊一个特别反常识的话题：为什么越忙的人越有时间？
<#0.5#>答案可能让你意外<#0.3#>(gasps)它跟"效率"其实没什么关系。
```

**报告：** 语气词映射 4 个（breath/chuckle/gasps）；停顿 2 处；破折号转停顿标记。

## 示例 4：技术文（代码剥离 + 行内发音）

```python

print(r.status_code)

注意"重载"读作 (chong2)载，不是 (zhong4)载。

## 示例 5：PPT/课件逐页朗读

**输入：**

```markdown
## 第 3 页：光合作用

**光反应**发生在类囊体薄膜上，**暗反应**（卡尔文循环）发生在基质中。

| 阶段 | 场所 | 产物 |
| --- | --- | --- |
| 光反应 | 类囊体薄膜 | ATP、NADPH |
| 暗反应 | 叶绿体基质 | 葡萄糖 |
```

**输出：**

```
第 3 页：光合作用
光反应发生在类囊体薄膜上，暗反应，卡尔文循环，发生在基质中。
表格内容：阶段，场所，产物。第一行：光反应，类囊体薄膜，ATP、NADPH。<#0.3#>第二行：暗反应，叶绿体基质，葡萄糖。
```

**报告：** 表格转为逐行朗读；标题剥标记；加粗 2 处剥离；括号"卡尔文循环"作为同位语保留。

## 示例 6：长文分段（超长提醒）

**输入：** 一篇 12000 字的公众号文章。

**处理：**
1. 完整转换后字符数 11500 → 超限。
2. 按段落边界切成 2 段：第 1 段 5900 字（流式），第 2 段 5600 字（流式）。
3. 每段内部保持停顿/语气词策略不变；段间手动衔接"（接上文）"提示。

**报告：** 已分段为 2 份，每份 <10000；均提示 >3000 建议流式输出。

## 示例 7：诗歌（停顿密集 + 保守处理）

**输入：**

```markdown
床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。
```

**输出（strong 档）：**

```
床前明月光<#0.5#>疑是地上霜<#0.5#>举头望明月<#0.5#>低头思故乡。
```

**说明：** 诗歌场景用户明确要求"一字一顿的韵味"时用 strong 档；默认 light 档下诗歌不插停顿，只保留换行。

## 示例 8：聊天记录/微信体

**输入：**

```
A：明天几点到？😄
B：大概下午三点吧……路上有点堵。
A：行，到了发消息！我在楼下等你～
```

**输出：**

```
A：明天几点到？(chuckle)
B：大概下午三点吧<#0.4#>路上有点堵。
A：行，到了发消息！我在楼下等你。
```

**报告：** emoji 映射 1；省略号转停顿；波浪号剥离；角色前缀保留（多人对话适合 WebSocket 分段 + 不同 voice_id）。

## 常见错误对照（不要这样做）

| ❌ 错误 | 问题 | ✅ 正确 |
| --- | --- | --- |
| `今天<#0.3#><#0.5#>很忙` | 连续停顿标记 | `今天<#0.3#>很忙` |
| `<#0.5#>开场白` | 停顿在开头 | 去掉开头标记，或换行分段 |
| `（laughs）` 全角括号 | 白名单是半角 | `(laughs)` |
| `(applause)` | 非白名单标签 | 删除，改 `(chuckle)` 或文字"掌声响起" |
| `2.8 以下模型 + (breath)` | 模型不支持 | 删除标签 |
| 人名中间插停顿 | 姓名被切断 | 不插 |
| `$S = k\ln W$` 直接保留 | 海螺会读乱 | 口语化 `S 等于 k 乘以 ln W` |
